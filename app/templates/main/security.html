Security & Privacy

We take the protection of your API keys and personal data seriously.

API Key Handling

Your Gemini API key is never exposed to the client browser after submission. It is stored securely in your active session and used strictly server-side to communicate with Google's APIs.

When your session expires or you log out, the key is permanently removed from our memory. We do not store API keys in any persistent database.

Encryption

All data transmitted between your browser and our servers is encrypted using industry-standard TLS (HTTPS).

Any sensitive session data is encrypted at rest using secure cryptographic algorithms (AES-256 equivalent) provided by our server framework.

Resume Data

When you upload a resume, we extract the text to provide context for your AI interviews. The original PDF files are not retained after processing.

The extracted textual profile is stored locally in your session or browser storage, giving you full control over your data.

Third-Party Processing

Your prompts, responses, and resume context are sent to Google's Gemini API for processing. We do not use your data to train our own models.

Please refer to Google's API Terms of Service regarding how they handle data submitted via their APIs.
