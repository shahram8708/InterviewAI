How to get your Gemini API Key

Follow these simple steps to generate your free API key and start practicing.

What is an API key? It's a special code that allows our platform to securely connect to Google's AI models to conduct your mock interviews.
1

Visit Google AI Studio

Go to the Google AI Studio portal to manage your API keys.

Open Google AI Studio
2

Sign in with Google

Sign in using your standard Google account credentials.

3

Navigate to API Keys

Once logged in, look for the "Get API key" or "API Keys" section in the left sidebar.

4

Create a new API key

Click the "Create API key" button in a new project.

5

Copy the generated key

Copy the long string of characters. Keep this secret and do not share it publicly.

6

Paste into platform

Return to our login page and paste the key to begin your interview practice.

Go to Login
